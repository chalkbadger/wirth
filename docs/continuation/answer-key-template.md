# Continuation answer key and scoring

The owner fills this template before the first run and keeps the actual key
outside the repository and unavailable to both runners until both finish.
The committed blank template is not an answer key. Follow the
[run procedure](../workflow.md#continuation-runs).

## Scoring after both runs

The owner scores each item or approves scores prepared by Wirth. Cite a section
or passage of each run's output for every score.

- **Correct:** the output meets the expectation and supports its conclusion;
  a request for owner input is correct when the key expects that next step.
- **Wrong:** the output contradicts the expectation or makes an unsupported guess.
- **Omitted:** the output does not address the item.

| Key ID | Run 1 score and output citation | Run 2 score and output citation |
| --- | --- | --- |
| K1 | | |

Report newly discovered gaps separately. Do not silently rewrite the key to
fit either output; record a disputed key item for the owner's decision. Scores
need not match. Record who scored, the owner's score approval, and any unresolved
disagreement. This is judgment evidence, not verification or a reliability rate.
